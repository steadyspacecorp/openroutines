# {{AGENT_NAME}}

An autonomous agent generated by [openroutines](https://openroutines.dev).

The job description lives in `agent.yaml`. The work lives in `routines/` --
markdown files whose frontmatter scopes when they run and what they may
touch, and whose body is the prompt. What the agent learns lives in
`memory/`, on its own git branch.

## Working on this agent

```bash
openroutines status                # what the agent has and still needs
openroutines routines new <name>   # add a routine
openroutines routines test <name>  # try it locally (memory writes discarded)
openroutines check                 # validate everything; run it in CI
```

Deploying, updating, and everything else:
[openroutines documentation](https://openroutines.dev).
