# {{AGENT_NAME}}

An autonomous agent generated by [OpenRoutines](https://openroutines.dev).

The agent's name and job description live in `openroutines.yml`, and both become standing context for every run. Name the agent for its domain and describe its durable mandate; routines define the particular recurring work and do not need to restate it. The routines live in `routines/` -- markdown files whose frontmatter scopes when they run and what they may touch, and whose body is the prompt. What the agent learns lives in `knowledge/`, on its own git branch.

## Working on this agent

```bash
openroutines status                # what the agent has and still needs
openroutines sync                  # pull the latest knowledge; read the files under knowledge/
openroutines routines new <name>   # add a routine
openroutines routines run <name> --skip-knowledge  # real run; knowledge writes discarded
openroutines check                 # validate everything; run it in CI
```

One GitHub quirk to ignore: the repo page will regularly offer
"Compare & pull request" for the `knowledge` branch, because the agent pushes to
it after every run. Knowledge is never merged into `main` -- there is no PR to
make. (GitHub has no setting to hide the banner.)
